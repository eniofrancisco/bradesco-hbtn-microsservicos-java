# Utilizando a SONG API REST

Este diretório contém os arquivos de resposta gerados a partir da utilização dos serviços da API REST criada com Spring Boot.

## Objetivo

Demonstrar o uso dos endpoints da SONG API para adicionar, consultar e listar músicas.

## Endpoints utilizados

- POST /api-song/addSong
- GET /api-song/welcome
- GET /api-song/findSong/2
- GET /api-song/allSongs

## Arquivos gerados

- respostaItemA.txt: resultado da inserção da música Sweet Child O 'Mine
- respostaItemB.txt: mensagem de boas-vindas da API
- respostaItemC.txt: resultado da busca pela música com id 2
- respostaItemD.txt: lista completa de músicas cadastradas
