# Projeto: Demo2 - Aplicação Spring Boot com Spring Initializr

Este projeto foi gerado com o Spring Initializr e demonstra a criação de um microsserviço simples.

## 📦 Estrutura

bradesco-hbtn-microsservicos-java/
└── 0x01/
    └── spring_boot_2/
        ├── demo2/
        │   └── src/
        │       └── main/
        │           └── java/
        │               └── com/
        │                   └── example/
        │                       └── demo2/
        │                           ├── Demo2Application.java
        │                           └── HelloWorldResource.java
        ├── demo2/pom.xml
        └── home_result.txt

## ⚙️ Características do Projeto

- Project: Maven
- Language: Java
- Spring Boot: 3.5.5
- Packaging: Jar
- Java: 17
- Dependencies:
  - Spring Web
  - Spring Boot DevTools
  - H2 Database
  - Lombok

## 🚀 Como executar

1. Importe o projeto na sua IDE (ex: Spring Tool Suite 4):
   - File >> Import >> Maven >> Existing Maven Project >> Selecione a pasta >> Finish

2. Execute o projeto com:

'''bash
mvn spring-boot:run
